# Wellness Check-in — How Are You, Really?

A responsive, interactive mood check-in prototype for a campus wellness project.

## Run it in VS Code
1. Create a folder named `wellness-checkin`.
2. Save `index.html` in that folder.
3. Open the folder in VS Code.
4. Open `index.html` in a browser, or use the Live Server extension.
5. To publish it, upload the folder to a static hosting service such as GitHub Pages, Netlify, or Vercel. Once you have the public URL, create a QR code that points to that URL.

## What it includes
- Emotion stickers / emoji choices.
- Mood, energy, need, and optional reflection questions.
- A supportive result and small suggested action for each mood.
- Restart button so students can reuse it whenever they need.
- Responsive design for phones.
- No accounts, analytics, database, or server submission. Answers stay in the current browser page and are cleared when restarting or reloading.

## Important
This is a non-clinical reflection tool, not a mental-health assessment or diagnosis. If you deploy it for students, consider adding a campus support contact and checking the wording with a qualified wellbeing professional.
